# Imitating a specific person's writing voice

Use this when the user asks you to write in *their own* style or to imitate a named account's style (e.g. "combine today's X hot topics with my posting style and write a tweet").

## 1. Read enough real samples first

- Do NOT generalize from the few posts visible at the top of a profile. Scroll the profile and collect a substantial sample (the user's own long-form posts are the highest-signal ones).
- Expand truncated posts ("Show more") — the long posts are where voice, structure and reasoning live, not the one-line banter.
- Confirm whose account it actually is before analyzing. Check the logged-in handle / profile header, not just whichever tab happens to be open. Distinguish the account owner from other people's profiles open in the browser.

## 2. Extract a voice profile before drafting

Identify, from the samples:

- **Recurring themes / 母题**: topics the person returns to again and again.
- **Structure**: how a post opens, how it transitions, whether it uses self-questioning, enumeration, a concrete anecdote, a closing question.
- **Diction**: filler words, transitions, whether technical terms are mixed with colloquial language.
- **Register control**: which topics get formal reasoning and which get profanity/emotion. Profanity is usually *punctuation*, not the main dish.
- **Signature personal details**: specific numbers, life context, tools they actually use. These make writing feel lived-in.

## 3. The "over-acting" trap (most common failure)

When a user says a draft has no "活人感 / bossy feeling / emotion", do NOT respond by stuffing in profanity, slogans, and short declarative sentences. That reads as *performed* humanity — obviously AI imitating a person.

Real human voice usually looks like:

-Thinking out loud: "最近一直在想一件事", "说起来…", "我又想到…"
-Self-correction / hedging: "那么针对这个问题呢", "其实也不是", "我不确定对不对"
-Concrete detail instead of abstract judgment: "睡前写好计划让它接着干" beats "非常努力"
-Colloquial transitions: "那么", "那", "其实", "说白了", "而"
-Profanity used sparingly, at emotional peaks only

Fake "bossy" voice (avoid): "醒醒吧", "无聊", "你们太浅了", "别装惊讶", stacked rhetorical questions, every other sentence a slogan.

## 4. Iteration protocol

If the user rejects a draft as "too 人机 / too 刻意":
1. Acknowledge specifically what you overdid (e.g. "堆粗口、喊口号").
2. Re-read the source samples rather than inventing a new persona.
3. Rewrite using the person's actual grammar and rhythm, keeping their real personal details.
4. Do not defend the rejected version.

## 5. Keep the substance

Style imitation must not erase the technical core. Keep the original argument, data points and structure from the researched material; only change the voice/layer. The best result merges the user's recurring themes with today's fresh material.
